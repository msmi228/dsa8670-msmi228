# GitHub Reading Reflection

## What I Learned

One thing I learned from the readings was how GitHub is more than just a place to store code. 
I already understood the basic idea of repositories and version control, but the chapters helped connect that to collaboration. 
Things like branches, commits, and pull requests make more sense when you think about multiple people working on the same project and needing a clear way to track changes.

## Challenge I Faced

One challenge I faced was that some of the written instructions felt more complicated than the actual process. 
I am more of a visual learner, so I ended up watching YouTube videos that showed each step in GitHub Desktop. 
Seeing someone create a branch, make a commit, and push the changes made it much easier for me to understand than just reading about it.

## How GitHub Can Help Future Team Projects

I can see GitHub being useful in future team projects because everyone can work on different parts of the project without constantly passing files back and forth or worrying about overwriting someone else’s work. 
It also gives the team a clear history of what was changed and makes it easier to review updates before adding them to the main project.
